## How to contribute

Thank you for contributing. We invite every partner to contribute — a new sample app, a bug fix, a dashboard or monitor, or any other resource you think other partners would find valuable.

### Bugs

- If you believe you've found a security vulnerability, don't open a GitHub issue — contact security@datadoghq.com directly.
- For anything else, check [existing issues](https://github.com/DataDog/dpn/issues) first to see if it's already been reported.
- If not, [open a new issue](https://github.com/DataDog/dpn/issues/new) with a clear title, a description, and any relevant details. Redact sensitive data like API keys or credentials.
- The more detail you provide, the faster we can help.

### Submitting a fix

If you've found and fixed a bug yourself, open a [pull request](https://github.com/DataDog/dpn/pulls). Describe the problem and the fix, and reference the related issue number if there is one.

### Sample apps

See [`CONTRIBUTING-sample-apps.md`](https://github.com/DataDog/dpn/blob/master/CONTRIBUTING-sample-apps.md) for the checklist, what we look for, and what to do if you'd rather not write the code yourself.

### Dashboards, monitors, and other resources

Open a [pull request](https://github.com/DataDog/dpn/pulls) to add a dashboard, monitor, or other resource you've found useful. Include a screenshot and a description of what it is and why it's valuable — resources built via the API or Terraform are especially welcome.
